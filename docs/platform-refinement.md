# 广州诊所发现首页 · 第二次本地改版

首屏定位“在广州，找到身边的诊所”，统计从既有 clinics 数据计算。
目录先于身体导览，保持区域、搜索、距离、地图、电话和照片行为。
仅汇医堂保留微信预约，其他机构保持电话确认，不共享小程序链接。
新增预约说明、四项到店准备、诊所信息收录区与平台/机构关系 FAQ。
原文章保持导航，不增加病症科普与机构预约捆绑的内容。

## 模型与资源

scripts/generate-body-mesh.mjs 原创程序化曲面，无外购或第三方模型。
新几何增加锁骨、肩胛、膝盖、肌腱与中性面部轮廓，保持无性特征。
矿物色哑光材质、本地生成微粒粗糙度、方向主光、补光与轮廓光。
模型706160字节，29424顶点、58844三角形，单一闭合连通面。
Three.js MIT 许可证见 docs/THREE-LICENSE.txt。
首屏插画、诊所实景与 logo 都是仓库既有资源，未引入新图片。

## 验收限制

本轮环境只有命令行，无可用浏览器控制/截图工具。
不能以之前截图声称新版通过桌面/手机视觉验收。
恢复浏览器连接后应检查首屏与目录、人体正背侧轮廓及热点、390/320手机布局和预约 QR。
本地预览 npm start，端口4173；静态导出继续支持 COS。
