# 汇医盟诊所查询网页

这是汇医盟网站的源码，包含诊所查询首页和养生指南文章页。仓库不包含本机依赖、构建缓存、公众号后台数据、域名验证文件或原站点的托管配置。

## 本地运行

需要 Node.js 22.13 或更新版本和 pnpm。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

构建静态网页：

```bash
pnpm build
```

静态输出位于 `dist/client`。请先在本地验证改动，不要直接覆盖线上网站。

预览构建后的文件（包括 `.html` 文章链接）：

```bash
pnpm start
```

预览只绑定本机 `127.0.0.1`。Vite 配置已移除对未上传的 `.openai/hosting.json` 和私有托管插件的依赖；网站仍按现有腾讯云 COS 方式静态导出。

## 验证与上线交接

本次验证包含 TypeScript 类型检查、静态构建、修改文件的 lint 检查，以及桌面 1366px、手机 390px/320px 布局与核心交互检查。静态导出时的养生指南及文章 `.html` 链接也需正常可用。

全仓库 `pnpm lint` 仍会报告原有组件库、`app/brand-mark.tsx` 和 `hooks/use-mobile.ts` 的检查问题；这些文件未在本次修改范围内。电话呼叫、微信小程序拉起和真实定位需要在目标手机环境验收。

审阅通过后，再由网站维护同事将 `dist/client` **内部的文件及文件夹**发布至现有网站托管位置。发布前备份当前站点，保留原有域名验证文件及托管配置；发布后按原流程刷新 CDN 缓存，并检查首页、文章、电话、地图及微信预约。当前改动本身不会修改域名或触发生产发布。

## 常用文件

- `app/page.tsx`：诊所查询首页、诊所资料与预约入口。
- `app/wellness/page.tsx`：养生指南首页。
- `app/wellness/content.ts`：养生文章内容。
- `app/globals.css`：网站样式。
- `app/directory.css`：新版诊所目录、共享页头与响应式样式。
- `app/site-header.tsx`：首页和养生指南共用页头。
- `public/`：网站图片及图标。
- `lib/site-links.ts`：开发与静态导出时的文章链接。
